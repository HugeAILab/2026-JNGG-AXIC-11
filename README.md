# 2026-JNGG-AXIC-11

2026 전남광주 기업 AX 혁신챌린지(문제해결형 AX 해커톤)

LNG탱크 품질 검사 영상 데이터를 활용한 불량 판정과 관리 시스템 개발

## 시스템 기능

- 불량 관리
- 불량 탐지 AI 모델
- 품질 검사 보고서 생성

## 설치와 실행

```
cd .\2026-JNGG-AXIC-11\Web

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

Copy-Item .env.example .env

python -m app
```
