# 용접 작업 전 품질 점검표

Rev. 0.1 / 2026-11-07 · 교육·시연용 서식 · 전문가 검토 전

## P00 사용 방법

본 점검표는 결함 예방과 품질 기록 교육을 위한 서식이다. 현장의 작업허가·안전점검·검사 계획을 대체하지 않는다. 실제 작업에 적용할 때는 현장 승인 절차와 점검 항목을 먼저 확인한다.

결과는 확인, 미확인, 부적합, 해당 없음으로 구분한다. 확인에는 근거를, 해당 없음에는 사유를 기재한다. 빈칸을 확인 완료로 취급하지 않는다. 필수 조건이 미확인되거나 부적합한 경우 해당 작업의 진행 여부를 현장 절차에 따라 확인한다. 조치 완료와 재확인을 구분하여 기록한다.

전류·온도·가스 유량 등 요구값은 해당 문서에서 확인한다. 본 서식은 임의의 수치 기준을 제공하지 않는다.

## P04 교육용 작성 예시

가상 상황: 가스 계통 항목에 확인 표시가 있으나 근거 기록이 없고, 전 교대자가 점검했다는 구두 설명만 있다.

작성 예시: “P02-06 미확인. 전 교대 점검 기록 미확보. 현장 절차에 따른 점검 결과와 확인자를 확보한 후 재확인 기록 예정.”

구두 설명을 기록할 수는 있으나 이를 실제 점검을 확인한 증빙과 혼동하지 않는다. 기록 누락이 장비 고장을 뜻하는 것도 아니다.

## P05 학습 확인

1. 빈칸인 항목을 이상 없음으로 처리할 수 있는가? — 아니며, 확인 여부와 근거를 확보해야 한다.
2. 해당 없음은 언제 사용하는가? — 작업 조건상 적용되지 않는 항목에 사유를 기록한다.
3. 적용 WPS의 개정본이 불명확하면 무엇을 하는가? — 담당자에게 적용본을 확인하고 임의 조건을 적용하지 않는다.
4. 청소 작업 완료 후 필요한 기록은? — 잔류물 제거 상태의 재확인 결과와 일시를 남긴다.
5. 점검 기록 누락은 곧 장비 불량인가? — 아니며, 미확인과 부적합을 구분하여 기록한다.
