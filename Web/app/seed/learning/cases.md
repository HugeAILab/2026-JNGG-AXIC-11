# 용접 결함 발생 및 보수 검토 사례집

Rev. 0.1 / 2026-11-07 · 교육·시연용 가상 사례 · 전문가 검토 전

실제 공사·업체·작업자·검사 실적을 나타내지 않는다. 사례별 처리 과정은 학습용이며 합격 수치, 승인자 또는 완료 실적을 가정하지 않는다. 실제 작업은 해당 기준과 승인 절차에 따른다. 관련 단원 번호는 「용접 결함별 상세 학습자료」와 연결된다.

## CASE-01 균열 의심 흔적과 연마 자국

연계 학습: L01

### 접수 상황

비드 인접부에서 분기된 선형 흔적을 확인했다. 작업자는 연마 자국이라고 설명했다.

### 확인 사실과 미확인 사항

선형 흔적의 위치·방향·분기 여부는 확인했지만 깊이와 원인은 미확인이다.

### 추가 확인

원본과 현장을 대조하고 해당 검사 절차로 균열 여부와 범위를 확인한다. 예열·층간온도 및 작업 기록도 대조한다.

### 보수 및 후속 처리

균열이 확인되어 보수가 필요한 경우 승인된 절차에 따라 제거하고 제거면을 검사한 후 재용접한다.

### 재검사와 종결 조건

잔류 균열 확인과 보수 후 재검사 결과, 필요한 검사 시점을 확보한다.

### 기록 연습

“[이음 번호]에서 [관찰 사실] 확인. [미확인 사항] 확인 전 판정 보류. 후속 확인: 원본과 현장을 대조하고 해당 검사 절차로 균열 여부와 범위를 확인한다. 예열·층간온도 및 작업 기록도 대조한다. 담당·예정일·확인 결과는 실제 처리 시 기록.”

### 토의 문제와 해설

작업자의 설명만으로 연마 자국으로 종결해도 되는가?

모범 답안: 아니다. 관찰 사실과 설명을 구분하고 해당 검사 결과를 확보해야 한다.

연계 학습: L02

### 보수 및 후속 처리

확인된 원인을 조치하고 검사 결과로 제거 범위를 정한 후 승인 절차로 재용접한다.

### 재검사와 종결 조건

보수 부위와 인접 구간의 재발 여부 및 필요한 내부 검사 결과를 확인한다.

### 기록 연습

“[이음 번호]에서 [관찰 사실] 확인. [미확인 사항] 확인 전 판정 보류. 후속 확인: 가스 유량·누설·노즐·외풍·표면 청정도와 이전 보수 조건을 점검한다. 담당·예정일·확인 결과는 실제 처리 시 기록.”

### 토의 문제와 해설

같은 방법으로 재용접하기 전에 무엇을 확인하는가?

모범 답안: 원인 점검 결과와 이전 보수 조건을 확보한다. 기록 누락만으로 가스 불량을 확정하지 않는다.

검사 결과·판정 근거·종결 확인이 모두 확보된 후 현장 절차에 따라 종결한다.

### 기록 연습

“[이음 번호]에서 [관찰 사실] 확인. [미확인 사항] 확인 전 판정 보류. 후속 확인: 대상 이음·보수 범위·적용 절차·재검사 방법과 예정 시점을 확인한다. 담당·예정일·확인 결과는 실제 처리 시 기록.”

### 토의 문제와 해설

다음 교대자가 기록해야 할 상태와 사유는?

모범 답안: 재검사 대기 또는 판정 보류로 기록하고 미확보 검사 결과와 후속 담당을 명시한다.
